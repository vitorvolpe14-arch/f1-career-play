# F1 Career Mobile — versão para navegador

Build WebGL do protótipo de pilotagem. O código-fonte fica em um repositório privado.
Para jogar no iPhone, abra no Safari: https://vitorvolpe14-arch.github.io/f1-career-play/

- **Circuito:** traçado de Monza derivado do OpenStreetMap — © OpenStreetMap contributors, licença ODbL
  (https://www.openstreetmap.org/copyright). O nome do circuito aparece só como referência, sem
  autorização verificada e para uso pessoal.
- **Carro e cenário:** provisórios (placeholder), gerados em código. Não há logotipos, equipes,
  pilotos nem patrocinadores reais.
- **Modos:** treino livre ou corrida contra 9 adversários da IA, todos fictícios, com 3, 5 ou 10 voltas e 4 níveis de dificuldade.
- **Diagnóstico:** acrescente `?debug` ao endereço para ver a posição do carro e da câmera. Use `?laps=1` para uma corrida de 1 volta.
